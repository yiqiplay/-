按键设置
这怎么用？（点开看说明）

普通模式（工具条没出来时）

  • 轻点按键 = 把按键发给电脑
  • 长按 0.6 秒 = 进入编辑，并选中这个按键
  • 普通模式下拖动不会移动按键（防误碰）

编辑模式（工具条出现时）

  • 拖动按键 = 换位置，靠近中线会吸附并显示十字参考线
  • 点按键 = 选中，右侧就是它的设置
  • 工具条从左到右：数量 · ＋ 添加 · 撤销 · 垃圾桶 删除选中 · 设置 打开完整设置 · 完成 退出编辑

各项设置

  • 名称：按钮上显示的文字
  • 绑定：点下去要发送什么。可以点下面的按键选择，也能直接输入
  • 形状 / 缩放：按钮外观
  • 长按连发：开启后按住不放会连续发送（方向键、退格很有用）
  • 切换开关：开启后按键在"亮 / 灭"之间切换

组合键怎么设

  • 连续点多个键即组合：点 Ctrl 再点 C → ctrl c
  • 同一个键再点一次即取消
  • 鼠标点击用 左键 / 右键 / 中键，和键盘键互斥

开启后，按住不放会连续发送（间隔从 120ms 逐渐加快到 45ms）， 适合方向键、退格这类需要连续触发的按键。

开启后，这个按键会在"亮/灭"之间切换。

位置只能在编辑模式里拖动，平时拖动不会移动按键（避免误碰）。 普通模式下长按按键也会进入编辑。

触屏按键设置
功能说明（第一次用建议看一下）

触屏按键是什么：悬浮在电脑画面上的透明按键，点一下就代替你按键盘/鼠标。 适合玩游戏、看视频这类需要反复按同一个键的场景。

怎么用

  • 点「显示」把按键浮到画面上（默认隐藏，不挡画面）
  • 屏幕上 轻点按键 = 发送；长按 0.6 秒 = 进入编辑
  • 点「进入编辑模式」可拖动按键换位置、改名称和绑定

位置怎么存：按画面比例保存，换手机、横竖屏都不会跑偏；重连后仍在。

找不到按键了：在下面的列表里点「编辑」，或进入编辑模式后在画面中央找 （新增的按键放在画面中央附近）。

悬浮按键

悬浮在画面上的按键：轻点发送按键、拖动换位置（位置自动记住）、 长按进入编辑。
