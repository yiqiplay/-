触控板式操作：单指滑动移动指针（手指不遮挡光标）；
轻点=左键单击，快速连点两次=双击，长按=按住拖动（再点一次放开），
双指轻点=右键，双指上下滑动=滚轮，双指捏合=调清晰度。
箭头尖端就是电脑指针的真实位置；按住或拖动时会显示一个同心圆点，
