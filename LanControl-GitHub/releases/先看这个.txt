========================================================
 局域网远程控制  v2.5.0   （手机控制电脑）
========================================================

【怎么用】

  1. 把整个文件夹拷到你想长期存放的位置
     （例如 D:\LanControl；请不要放在工作区或临时目录里）

  2. 双击「启动被控端.cmd」
     · 屏幕上会弹出控制面板
     · 首次运行 Windows 会弹防火墙提示 → 勾选【专用网络】→ 允许访问

  3. 手机连接到同一个 Wi-Fi，然后二选一：
     A. 手机相机扫控制面板左边那个二维码（最简单，已带配对码）
     B. 手机浏览器打开面板上的地址（形如 http://192.168.3.51:8848/），
        再输入面板上的 6 位配对码

  4. 手机端也可以装 LanControl-Android.apk（本文件夹里有），
     但**不装也能用**——手机浏览器直接开就行。


【控制面板上要认准两样东西】

  · 左边：大二维码
  · 右边：大号访问地址 + 超大号 6 位配对码
  · 顶栏上还有一个版本徽标（如 v2.5.0），
    用来确认手机连到的就是这份程序


【手机端界面说明】

  · 底部工具条固定显示，不依赖悬浮球：
      鼠标 / 虚拟鼠标 / 滚动 / 按键 / 打字 / 文件 / 电源 / 更多 / 全屏 / 收起
  · 工具条按钮多，窄屏可以左右滑动
  · 点「收起」把工具条收起来后，右下角会出现圆钮，点它随时唤回
  · 进入全屏后，工具条里仍有「全屏」按钮可以切回来
  · 右上角红色 ✕ = 断开连接
  · 顶栏 🔊 = 接收电脑的声音（开/关）


【两种用法，任选其一】

  ■ 绿色版（推荐，不用安装）
      · 双击「启动被控端.cmd」即可；不需要管理员权限、不写注册表

  ■ 安装程序（在「安装程序」子文件夹里）
      · LanControl-Setup-2.5.0.exe
          普通版：不需要管理员权限、不弹 UAC，装到当前用户目录
      · LanControl-Setup-2.5.0-admin.exe
          管理员版：安装时弹一次 UAC，但能**自动添加防火墙规则**
      · 安装包同样自带全部脚本、说明和手机 APK
      · 若提示「拒绝访问」：那是安装器要往 %TEMP% 解包时被环境拦了，
        换绿色版即可，功能完全一致


【常用脚本】

  启动被控端.cmd          启动
  结束被控端.cmd          停止并释放端口
  一键部署.cmd            建快捷方式 + 开机自启 + 放行防火墙（弹一次 UAC）
  卸载部署.cmd            撤销上面这些部署项
  清理旧版本.cmd          删除电脑上所有旧版本残留（保留当前目录）
  查找旧版本残留.cmd      只列出旧版本残留，不删除
  放行防火墙_双击即可.cmd  只处理防火墙规则
  诊断.cmd                逐项自检，连不上时先跑这个


【连不上怎么办】

  按顺序排查：
  1. 双击「诊断.cmd」，重点看 [8] 局域网 HTTP 连通性
  2. 确认手机和电脑在同一个 Wi-Fi（不能一个连路由、一个连热点）
  3. 确认防火墙已放行（用「放行防火墙_双击即可.cmd」，或在首次弹窗时点允许）
  4. 公司/校园网常开"AP 隔离"，设备之间无法互访
     → 临时用手机开热点，让电脑连到手机热点即可绕过
  5. 顶栏版本徽标如果显示的不是 v2.5.0，说明手机连到了旧的副本
     → 双击「清理旧版本.cmd」，只保留这一份，然后重新启动


【声音】手机端连上后，点顶栏的 🔊 即可开关"接收电脑的声音"。
  · 当前码率：**128 kbps**（8 kHz / 单声道 / 16 位 PCM）
    —— 按需求设定的默认值；原先跟随手机采样率是 768 kbps，已降到 1/6。
  · 电脑当前没在播放任何声音时，手机端就是安静的（正常现象，不是故障）。
  如果听到的是杂音而不是正常声音，可以这样判定问题在哪一端：

    1) 先在电脑上**放一首歌或一段视频**（必须正在出声，否则录不到东西）
    2) 双击运行同目录下的「录制声音测试.cmd」
       （它会录 10 秒并把文件放到桌面上：LanControl-录制测试.wav）
    3) 用播放器打开桌面上的 LanControl-录制测试.wav 听：
         · 声音正常 → 问题在手机端播放
         · 也是杂音 → 问题在电脑端采集
    把结果告我，就能只针对出问题的那一端修。

  手动命令（效果一样）：
      LanControlServer.exe --audio-record --seconds 10
