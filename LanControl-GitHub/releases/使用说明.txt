================================================================
        局域网远程控制 · 使用说明
     手机看屏 + 控制电脑（仅在局域网内使用）
================================================================

【一、这是什么】
    在被控电脑上运行「局域网远程控制 被控端」，用手机（连同一个 Wi-Fi）
    即可实时看到电脑画面，并用手机操作电脑的鼠标和键盘。
    画面、按键、文件全部只在你自己的内网里传输，不经过任何互联网服务器。

    功能：
      · 实时画面：多显示器切换、清晰度 / 分辨率 / 帧率可调
      · 鼠标控制：单指移动、轻点左键、长按右键、双指滚动、双指捏合调清晰度
      · 键盘输入：常用快捷键面板 + 手机输入法直接打字（支持中文）
      · 电源控制：锁定、睡眠、休眠、注销、重启、关机、关闭显示器
      · 文件传输：手机上传文件到电脑、下载电脑文件、新建文件夹、删除
      · 剪贴板：读取 / 写入电脑剪贴板
      · 安全：连接需要 6 位配对码，每次启动随机生成


【二、安装被控端（电脑）】
    1. 双击 LanControl-Setup-1.0.0.exe，按提示安装。
    2. 安装时可设置监听端口（默认 8848），建议勾选：
         √ 创建桌面快捷方式
         √ 开机自动启动被控端
         √ 添加 Windows 防火墙放行规则
         √ 复制手机安装包（APK）到桌面
    3. 若提示缺少 .NET 8 桌面运行时：
         打开 https://dotnet.microsoft.com/download/dotnet/8.0/runtime
         下载「Desktop Runtime x64」，安装后再运行本安装程序。
    4. 若没有勾选防火墙自动放行：首次运行被控端时 Windows 会弹出
       “Windows 安全中心警报”，请勾选「专用网络」并点「允许访问」，
       否则手机连不上。
    5. 安装完成后被控端会驻留在任务栏右下角托盘区（蓝色显示器图标），
       双击图标打开控制面板，可以看到访问地址和配对码。


【三、连接手机】
    方式 A：安装 APK（推荐）
        1. 把桌面上的「远程控制手机端.apk」传到手机
           （微信 / QQ / 数据线 / 手机浏览器下载均可）。
        2. 手机上点击安装（需允许“安装未知来源的应用”）。
        3. 打开 App 点「搜索电脑」，列表出现电脑后点击即可连接；
           搜不到时手动输入电脑地址，例如 192.168.1.100:8848。

    方式 B：手机浏览器（无需装 App）
        1. 电脑上双击托盘图标，看到访问地址，例如 http://192.168.1.100:8848/
        2. 手机浏览器打开该地址即可，界面与 APK 完全一致；
           （也可以直接扫描控制面板上的二维码）


【四、首次配对】
    连接后需要输入「配对码」：
      · 6 位数字，显示在被控端托盘提示和控制面板窗口上。
      · 点一下控制面板上的配对码即可复制。
      · 浏览器会记住，下次不用再输。
      · 每次重启被控端都会换新配对码；需要固定可用命令行指定：
             LanControlServer.exe --code 123456


【五、操作说明】
    两种操作方式（在右上「⋯」抽屉的「操作方式」里切换，或点底部「虚拟鼠标」按钮）：

    A. 直接点击（默认）——手指点到哪，电脑光标就跳到哪
      · 单指滑动          = 移动鼠标
      · 轻点（不滑动）    = 左键单击
      · 双击画面          = 双击
      · 长按约 0.5 秒     = 右键（按住拖动可右键拖拽）
      · 双指上下滑动      = 滚轮滚动
      · 双指捏合 / 张开   = 调整画面清晰度

    B. 虚拟鼠标（触控板式，★新增）——适合在手机上做精细操作
      手指在屏幕上滑动，电脑指针按相对位移移动，手指不会遮挡光标，
      手感和笔记本触控板一致。
      · 单指滑动          = 移动指针（灵敏度在抽屉里可选 慢/标准/快/很快）
      · 轻点              = 左键单击；快速连点两次 = 双击
      · 长按约 0.6 秒     = 按住左键进入拖动（再长按一次松开）；
                            抽屉里的「按住/松开左键（拖动）」按钮更直观
      · 双指轻点          = 右键
      · 双指上下滑动      = 滚轮滚动
      · 双指捏合 / 张开   = 调整画面清晰度
      · 抽屉「把光标移到屏幕中央」= 找不到指针时一键归位
      指针外观：蓝白箭头 + 圆环，拖动时变绿并带光晕，一眼看出是否按住。

    键盘：
      · 底部「按键」：常用快捷键面板
        （Alt+Tab、Alt+F4、Win、Win+D/E/R/L、Ctrl+C/V/X/Z/A/S/F/W、F1-F12、媒体键…）
      · 底部「打字」：在输入框里用手机输入法打字（支持中文），
        点「发送到电脑」注入到电脑光标处；勾选「先全选」可替换原有内容
      · 用电脑浏览器访问时，可以直接用物理键盘操作
    其他：
      · 右上「⋯」抽屉：切换显示器、画质、分辨率、帧率、全屏、剪贴板
      · 底部「文件」：浏览磁盘、上传 / 下载 / 删除文件、新建文件夹
      · 底部「电源」：锁定 / 睡眠 / 休眠 / 注销 / 重启 / 关机
        （关机、重启默认 30 秒后执行，可点「取消关机倒计时」撤回）


【六、常见问题】
    Q：手机搜不到电脑 / 连不上？
       · 确认手机和电脑连的是同一个 Wi-Fi。
       · 确认被控端在运行（托盘有蓝色显示器图标）。
       · 放行防火墙：控制面板 → Windows Defender 防火墙 →
         允许应用通过防火墙 → 找到 LanControlServer → 勾选「专用」。
       · 公司 / 学校网络常开启“AP 隔离”，设备之间无法互访。
         临时办法：用手机开热点，让电脑连到手机热点上。
       · 也可以手动输入地址：手机上填 电脑IP:8848。
    Q：提示“配对码不正确”？
       · 以电脑上当前显示的 6 位数字为准。
    Q：画面很卡 / 模糊？
       · 抽屉里把「画质」调成“流畅”，分辨率调成“小”，帧率改 8。
       · 尽量让手机和电脑连 5G 频段 Wi-Fi。
    Q：画面是黑的？
       · 电脑锁屏、显示器关闭时抓不到画面，先唤醒电脑。
       · 播放受 DRM 保护的视频时画面为黑，属正常现象。
    Q：有些窗口点不动？
       · 被控端以普通权限运行，无法操作“以管理员身份运行”的程序和 UAC 弹窗。
         需要时请右键被控端 →「以管理员身份运行」。
    Q：怎么改端口？
       · LanControlServer.exe --port 9000
       · 安装时也可以直接指定端口。
    Q：怎么卸载？
       · 设置 → 应用 → 已安装的应用 → 「局域网远程控制」→ 卸载。
       · 卸载会自动清理防火墙规则和开机自启项。
    Q：日志在哪？
       · %LOCALAPPDATA%\LanControl\server.log


【七、安全提醒】
    · 本软件只应在你自己的局域网内使用。
    · 不要在公共 Wi-Fi 或他人可访问的网络中长期开启；
      配对码是唯一凭据，请勿外泄。
    · 手机端不申请摄像头、麦克风、位置、通讯录等任何敏感权限。
