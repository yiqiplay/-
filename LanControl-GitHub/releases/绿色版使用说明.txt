================================================================
     局域网远程控制 · 免安装（绿色）版 使用说明
================================================================

    这一版不需要安装程序、不需要管理员权限，解压/拷贝到任意
    可写目录，双击「启动被控端.cmd」即可运行。

----------------------------------------------------------------
一、一键部署（推荐先做这一步）
----------------------------------------------------------------
    双击「一键部署.cmd」即可，它会依次：
      · 创建桌面 + 开始菜单快捷方式（指向当前文件夹，并设置工作目录）
      · 设置开机自启（当前用户，静默启动）
      · 添加 Windows 防火墙规则（会弹一次 UAC，点“是”即可）
      · 启动被控端，并把手机要用的网址打印出来
    每一步都会打印 [OK] / [X]，最后给出结论；全过程记录在同目录的
    deploy-log.txt。

    如果 UAC 没弹出来、或你点了“否”：
      脚本不会卡死，会明确说明防火墙规则未改动，并给出替代方案
      （启动被控端后，在 Windows 首次弹出的“安全中心警报”里勾选
        【专用网络】并允许访问，效果完全一样）。

    其他常用入口：
      · 只想放行防火墙：双击「放行防火墙_双击即可.cmd」
      · 查看部署状态：  powershell -File deploy.ps1 -Action status
      · 撤销部署：      双击「卸载部署.cmd」（删除快捷方式、自启项、
                        防火墙规则；程序文件夹本身保留）

----------------------------------------------------------------
二、放行防火墙（手机连不上的头号原因）
----------------------------------------------------------------
    防火墙规则**必须管理员权限**才能添加，两种做法任选其一：
      A. 双击「放行防火墙_双击即可.cmd」→ UAC 点“是”；
      B. 完全不需要管理员权限：双击「启动被控端.cmd」，
         首次监听时 Windows 会弹「Windows 安全中心警报」，
         勾选【专用网络】→【允许访问】。

    注意：**读取**防火墙规则同样需要管理员权限。非管理员时诊断脚本
    会显示 UNKNOWN，这**不代表**规则缺失。

----------------------------------------------------------------
三、快速开始
----------------------------------------------------------------
    1. 把整个文件夹拷到你想长期存放的位置（例如 D:\LanControl）。
    2. 双击「一键部署.cmd」（不需要右键），UAC 弹窗点“是”。
       不想部署也行：直接双击「启动被控端.cmd」一样能用。
    3. **看屏幕上的控制面板窗口**（它会自动弹出来，并且在任务栏里）：
         · **左半边是一个大二维码**（内容已含配对码）；
         · 右半边依次是**大号访问地址**和**超大号 6 位配对码**，
           点一下即可复制。
    4. 手机端三选一：
         A. **手机相机扫左边的二维码** —— 直接带着配对码打开控制网页，
           一个数字都不用输（推荐）；
         B. 手机浏览器手动输入右边那个地址 + 配对码（装不装 APK 都能用）；
         C. 装 LanControl-Android.apk → 打开 → 手动输入地址，或用
            「搜索电脑」自动发现。

    ⚠ 「搜索电脑」依赖 UDP 广播，而广播包经常被路由器、防火墙或安全软件
      拦截（企业/校园网尤其常见），所以它**不是可靠路径**。优先用扫码；
      扫不动就手动输入「地址 + 配对码」。

    连不上、看不到画面？双击「诊断.cmd」逐项检查（程序文件 / .NET /
    防火墙 / 端口监听 / 本机与局域网 HTTP 连通性）。

----------------------------------------------------------------
四、常用设置
----------------------------------------------------------------
    · 换端口：用记事本打开「启动被控端.cmd」，把
        set PORT=8848
      改成你要的端口（如 9000）。改完首次运行会再弹一次
      防火墙提示，同样选【专用网络】并允许。

    · 固定配对码（每次启动不再变化）：
        在 cmd 里进入本目录后执行
          LanControlServer.exe --code 123456

    · 文件传输的默认目录：
          LanControlServer.exe --files "D:\要共享的文件夹"
      不指定时默认是「文档\LanControl共享」。

    · 开机自启：把「启动被控端.cmd」的快捷方式放进
        %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
      （按 Win+R 输入 shell:startup 可打开该文件夹）

    · 退出程序（重要）：
        三种方式任选：
          A. 运行「结束被控端.cmd」——最省事，会自动通知程序优雅退出并释放端口；
          B. 右键托盘图标 →「退出」；
          C. 打开控制面板窗口 → 点右下角「退出被控端」按钮。
        注意：控制面板窗口右上角的 × 只是**最小化到托盘**，程序仍在运行
        （这是为了不让端口一直被占用而做的区分）；
        想用 × 直接退出，按住 Shift 再点 ×。

    · 重复双击启动器会怎样？
        不会启动第二个实例。它会自动找到正在运行的实例，把控制面板窗口
        弹出来给你看配对码，然后自己退出——所以托盘里只会有一个图标。

    · 托盘图标找不到？
        在任务栏右下角点那个小上箭头（隐藏的图标区）找蓝色显示器图标。
        如果确实没有：运行「结束被控端.cmd」清掉残留进程，再重新双击
        「启动被控端.cmd」；还不行就跑「诊断.cmd」。

----------------------------------------------------------------
五、常见问题
----------------------------------------------------------------
    Q：手机搜不到电脑 / 连不上？
       · 【推荐】用手机相机直接扫控制面板上的**二维码**（已带配对码），
         或手动输入面板上的地址（形如 192.168.3.51:8848）。
         注意：「搜索电脑」走的是 UDP 广播，很多路由器 / 防火墙 / 安全软件
         会拦截广播包，所以**搜不到并不代表连不上**。
       · 手机和电脑要在同一个 Wi-Fi 下。
       · 确认防火墙已放行：控制面板 → Windows Defender 防火墙 →
         「允许应用或功能通过 Windows Defender 防火墙」→
         找到 LanControlServer → 勾选「专用」。
       · 公司/校园网常开“AP 隔离”，设备之间无法互访，
         可用手机开热点、让电脑连手机热点。
       · 手机上手动填 电脑IP:端口 试试。

    Q：连上了、能看到控制界面，但画面一直是黑的/停在“正在建立画面通道”？
       · 先看那行小字诊断：“已收到画面帧”如果一直是 0，说明画面数据没传过来，
         多半是 Wi-Fi 太慢或被限速 —— 进右上「⋯」把「分辨率」调成“小”、
         帧率改成 8 再试。
       · 如果“解码失败”在涨，把「分辨率」调小一档；部分旧手机对
         大尺寸画面支持不好。
       · 也可以改用手机浏览器打开 http://电脑IP:8848/?maxw=1024
         强制用小尺寸画面验证。
       · 电脑上如果开着 VPN / 加速器 / 第二个网段，可能把画面流量带偏，
         临时关掉再试。

    Q：手机端全屏后工具条不见了？/ 工具条是不是个悬浮球？
       · 已按你的要求改过：**工具条永远是底部那条完整的固定栏**，
         不再变成悬浮球。
       · 点「进入全屏 / 沉浸模式」后：只隐藏顶部信息栏，**底部工具条保持
         完整贴底**，所有按钮照常可用。
       · 想全屏看画面时，点工具条最右边的「⌄ 收起」把工具条收起来，
         此时右下角会出现一个圆钮，点它随时唤回 —— 这是可选的。
       · 任何情况下都不会出现"工具条消失且找不回来"。
    Q：双击桌面快捷方式完全没反应（窗口和托盘图标都不出现）？
       这几乎都是**快捷方式指向的程序已经不在原处**造成的（比如移动/删除了
       旧文件夹、或换了新版本）。按顺序做：
         1. 双击「查找旧版本.cmd」——它会列出电脑上所有 LanControl 程序副本
            和所有指向它的快捷方式（含失效的）。
         2. 把「删除旧版本.cmd」放进旧文件夹里双击，把旧副本和失效快捷方式清掉。
         3. 从新文件夹里双击「一键部署.cmd」，
            它会重新创建指向**当前位置**的桌面快捷方式。
         4. 之后双击桌面「局域网远程控制」图标，会**直接弹出控制面板窗口**
            （显示访问地址和配对码），不需要再去托盘里找图标。
       如果新快捷方式依然没反应：
         · 在文件夹里直接双击 LanControlServer.exe 试试；
         · 若也不弹窗，运行「诊断.cmd」看程序文件是否被杀毒软件删了/隔离了；
         · 若 exe 被标记为“来自其他计算机”，右键 exe → 属性 → 勾选“解除锁定”。

    Q：托盘图标找不到 / 任务栏里也没有？
       · 这一版**不再依赖托盘**：控制面板窗口会在启动时自动弹出，并且
         常驻任务栏。关闭窗口只是"最小化"，程序继续运行 ——
         点任务栏上的蓝色显示器图标就能把它调回来。
       · 想让托盘图标也出现：在控制面板里点「让托盘图标常显」按钮。
         它会把图标从 Windows 的"隐藏的图标"溢出区提升为常显，并当场
         告诉你结果（注册表条目按 exe 路径区分，所以要在这份程序里点）。
       · 手动办法：点任务栏右下角的“小上箭头”，把里面的蓝色显示器图标
         拖到任务栏上即可常显。
       · 想彻底不用托盘：用  `LanControlServer.exe --no-tray`  启动。
       · 托盘是否创建成功记录在控制面板底部状态栏和日志里
         （`%LOCALAPPDATA%\LanControl\server.log`）。

    Q：卸载部署后桌面快捷方式还在？
       · 已修。新版卸载脚本会调用 `LanControlServer.exe --uninstall`，
         它会**遍历桌面/公共桌面/开始菜单/快速启动，解析每个快捷方式的目标**，
         把指向本程序的全部删除（不管叫什么名字），最后还会自动复查一遍。
       · 如果程序文件夹已被你删掉，脚本会用内置的兜底清理（按名字 + 按目标）。

    Q：虚拟鼠标的箭头位置和电脑指针不一致？
       · 已修：现在**箭头尖端**精确落在坐标点上（之前是把整个圆圈居中，偏了约 15px）。
       · 想自己确认：抽屉里点「校准检查」，画面会显示 9 个参考点，
         点其中一个，箭头尖端应正好落在它的圆心上。
       · 按住/拖动时会显示一个同心圆点，那是精确位置标记。

    Q：怎么听电脑的声音？
       · 手机端连接后，点顶栏的「🔇」按钮即可开始接收电脑正在播放的声音
         （图标变「🔊」表示已开启，再点一次关闭）。
       · 实现方式：电脑端用 WASAPI 回环采集"系统正在播放的音频"，
         免装任何虚拟声卡；采样率自动重采样为 16 kHz 单声道后推给手机。
       · 如果按钮是灰的：说明电脑端采集不到系统声音，鼠标悬停可看到原因。
         可在电脑上运行  LanControlServer.exe --audio-test  查看详细自检报告。
       · 注意：电脑**当前没有播放任何声音**时，手机端就是安静的（收不到数据包是
         Windows 的正常行为，不是故障）。请在电脑上放一段音乐/视频再试。

    Q：手机端「搜索电脑」搜不到？
       · 已重做。原来的按钮其实**没有做任何搜索**（只 ping 了自己），所以永远搜不到。
       · 现在的做法：**同网段直连扫描** —— 向 192.168.x.1~254 的 8848 端口逐一发起
         连接，能连上就是被控端。不再依赖 UDP 广播，因此不受路由器/防火墙拦截影响。
       · 网段来源：你上次连接过的地址（或当前页面地址）。
         所以**第一次请手动输入地址连一次**，之后"搜索电脑"就能自动扫到。
       · 需要约 3~5 秒，期间会显示扫描进度。

    Q：手机端全屏后图标不见了？
       · 已修。虚拟鼠标（🖰）和断开连接（⏻）现在**任何模式下都可见**：
         顶栏里各有一个；进入沉浸/全屏后顶栏隐藏，断开按钮会变成右上角的
         悬浮红色圆钮常驻，虚拟鼠标也可在底部工具条里切换。
    Q：双击 cmd 一闪而过？
       · 说明程序没启动成功：确认 4 个程序文件与 cmd 在同一目录，
         并且没有被杀毒软件隔离。

    Q：提示缺少 .NET？
       · 需要 .NET 8 桌面运行时（Windows 11 一般自带）。缺的话去
         https://dotnet.microsoft.com/download/dotnet/8.0/runtime
         下载「Desktop Runtime x64」安装。

    Q：有些窗口点不动？
       · 普通权限下无法操作“以管理员身份运行”的程序和 UAC 弹窗，
         需要时右键以管理员身份运行 LanControlServer.exe。

    更多功能与操作说明见「使用说明.txt」。
    其中手机端有两种操作方式，可在右下「⋯」抽屉里切换：
      · 直接点击（默认）：手指点到哪，光标跳到哪
      · 虚拟鼠标（触控板式）：单指滑动移动指针、轻点左键、长按拖动、
        双指轻点右键，适合精细操作

（完）
