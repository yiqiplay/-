# 局域网远程控制（手机控制电脑）

在同一局域网内，用安卓手机实时查看并操作电脑屏幕的完整解决方案。
**电脑端是被控端（Server），手机端是控制端（Client）。** 全部数据只在你自己的内网中传输，不经过任何互联网服务器。

---

## 交付物（全部在 `dist\` 目录，v2.0.0）

| 文件 | 说明 |
| --- | --- |
| `dist\LanControlServer.exe` 等 4 个文件 | ⭐ **被控端主程序**：拷到任意可写目录即可运行，双击就出控制面板 |
| `dist\启动被控端.cmd` | 启动（首次运行会弹防火墙授权，勾“专用网络”并允许） |
| `dist\一键部署.cmd` | 一步配好：桌面/开始菜单快捷方式 + 开机自启 + 防火墙规则（弹一次 UAC） |
| `dist\卸载部署.cmd` | 撤销上面这些部署项（程序文件夹保留） |
| `dist\清理旧版本.cmd` | **删除电脑上所有旧版本残留**（旧进程/快捷方式/自启项/防火墙规则/旧目录），保留当前目录 |
| `dist\查找旧版本残留.cmd` | 只列出旧版本残留，不删除 |
| `dist\放行防火墙_双击即可.cmd` | 只处理防火墙规则（弹一次 UAC） |
| `dist\诊断.cmd` | 逐项自检：程序文件 / .NET / 防火墙 / 端口监听 / 局域网连通性 |
| `dist\结束被控端.cmd` | 停止被控端并释放端口 |
| `dist\LanControl-Android.apk` | 手机端 App（可选；**不装也能用**，手机浏览器直接开即可） |
| `dist\LanControl-Setup-2.0.0.exe` | 安装程序（不需要管理员、不弹 UAC） |
| `dist\optional\LanControl-Setup-2.0.0-admin.exe` | 可选管理员版：安装时能自动加防火墙规则 |
| `dist\traytest\` | 托盘图标诊断工具（`证明托盘修复.ps1` 可一键验证） |

> ### 怎么连手机（v2.0.0 起以扫码为主路径）
> 1. 双击 `启动被控端.cmd`，屏幕上会弹出**控制面板**，左侧是一个**大二维码**，
>    右侧是大号地址与 6 位配对码。
> 2. 手机相机扫这个二维码 —— 会带着配对码直接打开控制网页，**不用手输任何数字**；
>    扫不动就手动在手机浏览器输入右侧那个地址 + 配对码。
> 3. 前提：手机和电脑在同一个 Wi-Fi 下，且首次运行时在 Windows 防火墙弹窗里点了“允许访问”。
>
> 二维码由程序内置生成器绘制，**已用两套独立解码器（规范级解码器 + jsQR）逐张验证过可正常解码**
> （见 `tools\qr-decode.mjs`、`tools\test-qr.mjs`）。

> ### ⚠️ 安装程序报「拒绝访问」怎么办
> Inno Setup 安装包启动时要往 `%TEMP%` 解包，并在受限环境里申请提权；如果当前环境
> （例如被沙箱/安全策略限制的会话）不允许这两件事，安装器会**一启动就报“拒绝访问”**。
> 这不是安装包损坏。**直接用 `dist\` 里的绿色版**（第 1~3 行的程序文件 + `.cmd` 启动器）即可，
> 功能与安装版完全一致。
>
> 连不上、没画面时，双击 **`诊断.cmd`**：它会逐项检查程序文件、.NET 运行时、
> 防火墙规则、端口监听、本机与局域网 HTTP 连通性并给出结论。

## 功能

- **实时画面**：多显示器枚举与切换，清晰度（45/62/80）、输出宽度（1024/1280/1920/2560）、帧率（8/15/24）可调，自适应丢帧防止延迟累积
- **两种鼠标操作方式**（手机端可切换）：
  - **直接点击**：手指点到哪，电脑光标就跳到哪；轻点=左键，长按=右键，双指滚动，双指捏合调清晰度
  - **虚拟鼠标（触控板式）**：单指滑动按相对位移移动指针，**手指不遮挡光标**；轻点=左键、连点两次=双击、长按≈0.6s 按住拖动（再长按松开，抽屉里也有「按住/松开左键」按钮）、双指轻点=右键、双指滚动、双指捏合调清晰度；灵敏度 慢/标准/快/很快 可选；「把光标移到屏幕中央」一键归位。指针为蓝白箭头+圆环，按住拖动时变绿带光晕
- **键盘输入**：常用快捷键面板（Alt+Tab、Alt+F4、Win+D/E/R/L、Ctrl+C/V/X/Z/A/S/F/W、F1–F12、媒体键…），手机输入法文本注入（Unicode 直注 + 剪贴板粘贴两种路径，支持中文）
- **电源控制**：锁定、睡眠、休眠、注销、重启、关机（默认 30 秒延迟，可取消）、关闭显示器、任务管理器
- **文件传输**：磁盘/目录浏览（含桌面/下载/文档等快捷入口）、上传（多选、带进度）、下载（支持 Range 断点）、新建文件夹、重命名、删除
- **剪贴板**：读取电脑剪贴板到手机、把手机剪贴板写到电脑
- **安全**：6 位配对码鉴权（每次启动随机生成，可用 `--code` 固定）
- **能力自检**：启动时自检输入注入是否可用，不可用时在日志、控制面板和手机端同时明确提示（避免出现"点了没反应却不知道为什么"）
- **零依赖手机端**：界面是内嵌的 WebView，安卓 App 本体只有 20 多 KB；也可以不装 App，直接用手机浏览器访问

## 快速开始

### 方式 A：免安装绿色版（最省事，权限限制环境下也能用）

1. 把 `dist\LanControl-Portable\` 整个文件夹拷到电脑上任意可写位置，例如 `D:\LanControl`。
2. 双击其中的 `启动被控端.cmd`。
3. 首次运行若弹出「Windows 安全中心警报」→ **勾选“专用网络” → 允许访问**
   （已实测：被控端在本机各网卡上监听正常，能否被手机连入只取决于这条防火墙放行）。
4. 双击托盘里的蓝色显示器图标 → 看到访问地址和 6 位配对码。
5. 手机装 `LanControl-Android.apk`（或浏览器直接打开那个地址）→ 输入配对码。

### 方式 B：运行安装程序

双击 `dist\LanControl-Setup-1.0.0.exe`，按向导完成（默认按当前用户安装到
`%LOCALAPPDATA%\LanControl`，不弹 UAC）。建议勾选：
- 创建桌面快捷方式
- **开机自动启动被控端**
- 复制手机安装包（APK）到桌面

> 若安装器一启动就报「拒绝访问」，见上文交付物表格下的说明：
> 改用绿色版，或双击 `dist\以兼容模式运行安装程序.cmd`。
>
> 想连防火墙规则一起自动配好，可改用 `dist\optional\` 里的管理员版安装程序（会弹一次 UAC）。
>
> 需要 .NET 8 桌面运行时（Windows 11 与已更新的 Windows 10 通常已内置）。安装程序会自动检测，缺失时给出官方下载地址。

### 装手机端
把 `LanControl-Android.apk` 传到手机安装，打开后点「搜索电脑」自动发现；
或直接用手机浏览器打开电脑上显示的地址，例如 `http://192.168.1.100:8848/`。

### 配对
电脑托盘图标双击 → 控制面板上显示 **6 位配对码**和访问地址（含二维码）。手机端输入配对码即可进入。

## 命令行参数（被控端）

```
LanControlServer.exe [--port 8848] [--code 123456] [--files D:\共享目录]
```

| 参数 | 说明 |
| --- | --- |
| `--port` | 监听端口，默认 8848（也支持 `--port=9000` 写法）；安装时选择过端口则优先用安装设置 |
| `--code` | 固定配对码；不指定则每次启动随机生成 6 位数字 |
| `--files` | 文件传输的默认起始目录，默认是「文档\LanControl共享」 |

托盘菜单还提供：复制访问地址、开机自启开关、打开日志目录、退出。

## 通信协议（便于二次开发）

- 页面：`GET /`（内嵌 Web UI）、`/web/app.css`、`/web/app.js`
- 健康检查：`GET /ping` → `{"ok":true,"app":"LanControl",...}`
- 控制通道：`GET /ws`（WebSocket 升级，文本帧为 JSON 指令，二进制帧为画面）
- 文件：`GET /api/files?path=`、`POST /api/delete|mkdir|rename`、`POST /upload?dir=`、`GET /download?path=`

二进制画面帧格式：`[0]=协议版本(1) [1]=显示器索引 [2..5]=原始宽 float32 [6..9]=原始高 float32 [10..13]=时间戳 float32 [14..]=JPEG`

主要 JSON 指令：
`auth` `ping` `startStream` `stopStream` `setMonitor` `mouse`(move/down/up/click/scroll/hscroll) `key`(tap/down/up) `text` `shortcut` `power` `volume` `media` `clipboardGet` `clipboardSet` `cursor` `sysinfo` `listDir` `mkdir` `delete` `launch` `disconnect`
服务端推送：`welcome` `authResult` `streamState` `stats` `monitors` `powerResult` `clipboard` `sysinfo` `dir` `simpleResult` `cursor` `error` `bye`

## 实测记录（本机真实运行结果）

### 本轮修复（v1.0.1）

| 问题 | 根因 | 修复与验证 |
| --- | --- | --- |
| **无法修改防火墙规则** | `netsh advfirewall firewall add/delete/show` **全部需要管理员权限**，实测非管理员执行返回 `The requested operation requires elevation`。而部署脚本只是打印一句"请以管理员身份运行"，并没有能力自己提权（`.cmd` 无法发起 UAC 提示）；更糟的是旧版 `诊断.cmd` 在非管理员下读不到规则，却把"读不到"**误报成"规则缺失"** | 新增 `firewall.ps1`：`-Elevate` 时会自己发起 UAC 提权（你只需点一次"是"），并支持 `add/remove/status`；提权失败或无人应答时给出**无需管理员权限的替代方案**（等 Windows 首次弹出的"安全中心警报"里勾选专用网络并允许），并有 90s 超时保护避免卡死。新增一键脚本「放行防火墙_双击即可.cmd」；部署/卸载脚本改为调用它；`诊断.cmd` 的防火墙段在无管理员权限时改为显示 **UNKNOWN（并明确说明这不代表缺失）** |
| **点启动器后"没正常启动、端口不监听"** | 两个我自己引入的阻塞：①托盘图标重试循环跑在 **UI 线程、且在消息循环启动之前**（`Thread.Sleep` 15×2s），托盘一旦创建失败就把进程卡死 30 秒；②启动器脚本里用 `Add-Type` 内联编译 C#，在受限机器上会**永久挂起** | ①重试改到后台线程；②启动器重写为**零内联编译**、所有网络调用带短超时。实测：直接启动监听 OK、启动器识别"已在运行"并报告 PID/版本、`status` 秒回不卡 |
| **启动失败时看不到原因** | 启动器只打印一句"未启动" | 新增 `--status-file`：服务端把 `state/port/pid/tray/injection/sessions/error` 落盘；启动器失败时自动打印**状态文件 + 日志末尾 12 行** |
| **托盘图标"不在"（探明真因）** | `TrayDiag` 抓到实据：`HKCU\Control Panel\NotifyIconSettings` 里我们的条目 `IsPromoted=0` —— Windows 默认把新通知区图标塞进"隐藏的图标"溢出区（该机 46 个图标只有 4 个常显） | ①启动 1.2 秒后自动把条目 `IsPromoted` 置 1；②控制面板新增「托盘图标常显」按钮；③控制面板窗口常驻任务栏。注意：注册表条目**按可执行文件路径区分**，必须从最终长期使用的那份程序里点这个按钮 |
| **虚拟鼠标箭头与指针错位** | `#vcursor` 用 `margin:-23px` 把 46×46 的指示器居中在坐标点，而箭头画在盒子中央 → 偏移约 15px | 箭头**尖端**对齐坐标点（`margin:-15px -14px`）；新增同心圆点；抽屉里「校准检查」叠加 3×3 参考点，肉眼可验 |
| **卸载部署后快捷方式没删掉** | 卸载脚本只按硬编码文件名单删，旧版本用过别的名字 | 新增 `--uninstall`：遍历桌面/公共桌面/开始菜单/快速启动，**解析每个 .lnk 的目标**逐个删除，最后自动复查 |
| **托盘图标消失后再也不回来（已复现）** | `TaskbarCreated` 被硬编码成 `0x8001`（真实消息号系统随机分配，本机实测 `0xC0BB`） | 改用 `RegisterWindowMessage("TaskbarCreated")`；附复现工具 `tools\TrayWatcher` 与绿色版里的 `traytest\证明托盘修复.ps1` |
| **虚拟鼠标指针突然跳回原处** | 注入失败时仍回传"真实（没动）的光标位置"，手机端采用后指针被拽回 | 回传附 `trusted` 标记，位置对不上时手机端不采用 |
| **虚拟鼠标指针会突然跳回屏幕中央** | 电脑端注入输入失败时，`cursor` 回传的仍是**真实（没动）的光标位置**；手机端 250ms 后接受该位置，于是本地指针被反复拽回去（实际观测到被拽到 x=0.1356 这种残留坐标） | 服务端记录"要求注入的目标位置"，回传时附带 `trusted` 字段：真实位置与目标偏差 >24px 即判为不可信；手机端对 `trusted:false` 的位置**一律不采用**。实测：注入被拒时会话里 `trusted:false`，指针不再被拉回。另外把指针位置也存进 localStorage，刷新/重连不再回到中央；首帧未到时按舞台尺寸兜底定位，避免指针被画到角落 |
| **再次启动后托盘图标依旧不在** | 托盘图标建是建了（日志有"托盘图标已创建"），但 Windows 把它折叠进"隐藏的图标"里，用户找不到；也可能被同名的旧实例占着 | ①控制面板**常驻任务栏**（`ShowInTaskbar=true` + 程序图标 + 窗口内提示文字），保证有一个看得见、点得到的入口；②新增 `--no-tray` 模式（完全不建托盘，只留任务栏窗口）；③`launch-helper.ps1 -Action status` 现在会列出该进程的可见窗口标题，并显示"输入注入被阻止"警告；④新增 `-Action kill` 按端口强制收尾残留。实测：`--no-tray` 下窗口可见、helper 能报出窗口标题 |
| **托盘菜单"打开控制面板"点了没反应** | 控制面板窗口是在**后台线程**创建的 —— WinForms 窗口必须在 UI 线程创建，否则窗口能显示但点不动、或干脆不显示 | 引入隐藏的 UI 锚点窗口（`Winsta`）承载消息循环，所有窗口/托盘操作统一通过 `RunOnUi()` 切回 UI 线程；显示时额外做 `ShowWindow(SW_RESTORE)` + `SetForegroundWindow` 置前。实测：枚举窗口确认 `局域网远程控制 · 被控端 visible=True`，位置尺寸正常 |
| 托盘图标消失 | 进程被强杀/Explorer 重启后图标不会自动恢复；重复启动的旧版本还会残留 | 监听 `TaskbarCreated` 广播，Explorer 重启后自动重建托盘图标并恢复控制面板；启动日志新增"程序路径"，便于确认跑的是哪一份 |

| 快捷方式双击毫无反应 | 快捷方式指向的程序已被移动/删除（旧副本被清理或换版本），成了死链接；且原来用 VBScript 创建 .lnk，在受限环境下会静默失败 | 改由程序自己用 Windows Shell COM（`IShellLink`）创建快捷方式，指向**当前实际路径**并设置工作目录，参数带 `--show`；`--install` 会回读 .lnk 校验目标是否一致并打印出来 |

| 重复启动后托盘图标不出来 | 第二个实例因端口被占用弹错误框后**静默退出**，用户以为"快捷方式没反应" | 加全局互斥体做单实例：检测到已有实例时**通知它弹出控制面板**，本次进程安静退出。实测：第 2 次启动输出"ALREADY RUNNING"，进程数仍为 1 |
| 退出软件后端口不释放 | 控制面板窗口右上角 × 只隐藏窗口；退出路径不可靠，进程残留 | 新增统一 `Shutdown()`（释放托盘 → 关监听 → 停推流）+ `Environment.Exit` 兜底；窗口 × 改为"最小化到托盘"，Shift+× 或托盘「退出」或控制面板「退出被控端」才真正退出。实测：停止后端口立即释放 |

## 已知限制

- 被控端以**普通权限**运行，无法操作「以管理员身份运行」的程序和 UAC 安全桌面；需要时请以管理员身份启动被控端。
- 电脑锁屏、显示器关闭或播放 DRM 保护内容时抓不到画面（Windows 会话隔离所致）。
- 网络需允许设备互访；公司/校园网常开启 AP 隔离，此时可用手机热点。
- 画面传输为 MJPEG 流（非 H.264），2560×1600@15fps 约 2–3 Mbps，2.4G Wi-Fi 下建议降到 1024 宽 / 8fps。
- 默认（免管理员）安装的监听端口为 8848；要换成其他端口请用 `dist\optional\` 的管理员版安装程序，
  或直接带参数运行：`LanControlServer.exe --port 9000`（此时需自行在防火墙上放行该端口）。
